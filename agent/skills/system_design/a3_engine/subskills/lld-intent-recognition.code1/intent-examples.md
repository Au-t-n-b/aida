## 无法识别 — FAILED

| 用户输入 | 输出 |
| --- | --- |
| 帮我写一首诗 | 当前问题不属于LLD设计支持范围，请输入地址规划、互联规划、接入规划、LLD设计等相关指令。 |
| 今天天气怎么样 | 当前问题不属于LLD设计支持范围，请输入地址规划、互联规划、接入规划、LLD设计等相关指令。 |
| LLD | 当前问题不属于LLD设计支持范围，请输入地址规划、互联规划、接入规划、LLD设计等相关指令。 |

> 注：单独 `LLD` 不能匹配 `LLD设计`，也无法触发 LLD 特殊规则（缺少"生成"或"融合"），因此走 FAILED。若业务希望单独 `LLD` 进入追问，可在后续版本调整。
