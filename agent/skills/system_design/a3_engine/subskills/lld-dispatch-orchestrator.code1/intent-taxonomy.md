# LLD 意图分类树

所有识别结果必须来自本词汇表中的标准名称。一级、二级、三级均可作为最终输出命令。

## 一级分类

地址规划、互联规划、接入规划、网管规划、路由规划、LLD设计、文件查询、知识问答、使用指引、文件生成、数据检查、信息查询、服务器基础配置规划、命名替换、其它

| --- | --- |

| LLD设计 | 融合LLD设计、生成LLD设计 |
| 文件查询 | 输出件查询、输入件查询 |
| 知识问答 | LLD设计知识、系统能能力与使用指南 |
