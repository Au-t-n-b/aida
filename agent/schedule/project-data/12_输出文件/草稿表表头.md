# 草稿表表头

## 一、文档作用

本文档描述 `草稿表.xlsx` 的表头结构，用于后续模型读取排期草稿、按项目场景、产品形态、散热方式、管理单元和排期 JSON 数据检索尚未正式确认的排期结果。

## 二、表头字段

| 字段    | 类型       | 必填  | 说明                     |
| ----- | -------- | --- | ---------------------- |
| 关系ID  | number   | Y   | 草稿记录或关系记录唯一标识。         |
| SLA版本 | number   | N   | SLA 版本号。               |
| 阶段编号  | number   | Y   | 排期阶段编号。                |
| 版本号   | number   | Y   | 草稿数据版本。                |
| 项目编号  | string   | Y   | 项目唯一标识。                |
| 项目场景  | string   | Y   | 项目场景，如集群集成。            |
| 产品形态  | string   | Y   | 产品形态，如 A3。             |
| 散热方式  | string   | Y   | 散热方式，如 liquid_cooling。 |
| 到货文件  | string   | N   | 关联的到货文件或到货数据标识。        |
| 管理单元  | string   | N   | 管理单元，如机房-PoD。          |
| 排期数据  | string   | Y   | JSON 形式的排期结果数据。        |
| 状态    | string   | N   | 草稿记录状态。                |
| 创建时间  | datetime | N   | 记录创建时间。                |
| 创建人   | string   | N   | 记录创建人。                 |

## 三、md 表头与 Excel 变量映射

| md字段 | Excel变量 | Excel文件 | Sheet | 表头行 | 说明 |
|---|---|---|---|---|---|
| 关系ID | REL_ID | `草稿表.xlsx` | `sheet0` | 1 | 草稿记录或关系记录唯一标识。 |
| SLA版本 | SLA_VERSION | `草稿表.xlsx` | `sheet0` | 1 | SLA 版本。 |
| 阶段编号 | STAGE | `草稿表.xlsx` | `sheet0` | 1 | 阶段编号。 |
| 版本号 | VERSION | `草稿表.xlsx` | `sheet0` | 1 | 草稿版本号。 |
| 项目编号 | PROJECT_ID | `草稿表.xlsx` | `sheet0` | 1 | 项目唯一标识。 |
| 项目场景 | PROJECT_SCENE | `草稿表.xlsx` | `sheet0` | 1 | 项目场景。 |
| 产品形态 | PRODUCT_FORM | `草稿表.xlsx` | `sheet0` | 1 | 产品形态。 |
| 散热方式 | COOLING_METHOD | `草稿表.xlsx` | `sheet0` | 1 | 散热方式。 |
| 到货文件 | ARRIVAL_FILE | `草稿表.xlsx` | `sheet0` | 1 | 关联到货文件或数据标识。 |
| 管理单元 | MANAGEMENT_UNIT | `草稿表.xlsx` | `sheet0` | 1 | 管理单元。 |
| 排期数据 | SCHEDULE_DATA | `草稿表.xlsx` | `sheet0` | 1 | JSON 形式排期结果。 |
| 状态 | STATUS | `草稿表.xlsx` | `sheet0` | 1 | 草稿记录状态。 |
| 创建时间 | CREATED_AT | `草稿表.xlsx` | `sheet0` | 1 | 创建时间。 |
| 创建人 | CREATED_BY | `草稿表.xlsx` | `sheet0` | 1 | 创建人。 |
