# 风险应对措施表头

## 一、文档作用

本文档描述 `风险信息_应对措施.xlsx` 的表头结构，用于后续模型按措施名称、责任人、计划/实际完成时间与状态检索风险应对动作，并与 `风险信息表` 通过 `问题ID` 串联，支撑风险解释材料中的保障措施与闭环跟踪。

## 二、表头字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 措施ID | number | Y | 应对措施唯一标识，对应 Excel `MEASURE_ID`。 |
| 外部ID | number | N | 外部系统关联标识，对应 `FOREIGN_ID`。 |
| 任务ID | string | N | 关联任务标识，对应 `task_id`。 |
| 项目ID | string | Y | 所属项目标识，对应 `PROJECT_ID`。 |
| 问题ID | string | Y | 关联的风险问题标识，对应 `ISSUE_ID`；与 `风险信息表` 的 `问题ID` 对齐。 |
| 措施名称 | string | Y | 应对措施描述，对应 `MEASURE_NAME`。 |
| 责任人 | string | Y | 措施执行责任人（可含工号），对应 `RESPONSIBLE_PERSON`。 |
| 计划完成时间 | datetime | N | 措施计划完成时间，对应 `PLANNED_COMPLETE_TIME`。 |
| 实际完成时间 | datetime | N | 措施实际完成时间，对应 `REAL_COMPLETE_TIME`。 |
| 进展 | string | N | 措施执行进展，对应 `PROGRESS`。 |
| 状态 | string | Y | 措施生命周期状态（如「已关闭」），对应 `STATUS`。 |
