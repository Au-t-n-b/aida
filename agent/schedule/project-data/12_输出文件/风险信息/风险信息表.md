# 风险信息表头

## 一、文档作用

本文档描述 `风险信息.xlsx` 的表头结构，用于后续模型按风险分类、等级、责任人、影响与状态检索项目级风险事项，为排期解释、风险协同与关闭留痕提供数据依据。与 `04_计划基线` 中按活动挂载的「风险五列」规则表互补：本表记录项目执行过程中的实际风险条目（含 Agent 自动识别与人工录入）。

## 二、表头字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 风险ID | number | Y | 风险记录唯一标识，对应 Excel `id`。 |
| 修改标记 | number | N | 记录是否被修改过，对应 `modified`。 |
| 项目ID | string | Y | 所属项目标识，对应 `project_id`。 |
| 问题ID | string | Y | 风险问题唯一标识，与 `风险应对措施表` 的 `问题ID` 关联。 |
| 风险分类 | string | Y | 风险大类名称，对应 `name`（如「产品解决方案」「物料齐套风险」）。 |
| 规则ID | string | N | 命中规则标识，对应 `rule_id`；Agent 识别场景常为空。 |
| 风险描述 | string | Y | 风险现象或判断依据的详细描述，对应 `description`。 |
| 风险等级 | string | Y | 高 / 中 / 低，对应 `level`。 |
| 责任人 | string | Y | 风险跟进责任人或角色，对应 `owner`（如 TD、远程交付方案专家）。 |
| 风险影响 | string | N | 对交付、关键平面或关键设备的影响说明，对应 `effect`。 |
| 进展 | string | N | 风险处置进展（如「新增」），对应 `progress`。 |
| 状态 | string | Y | 风险生命周期状态（如「已关闭」），对应 `status`。 |
| 开始时间 | datetime | N | 风险识别或登记时间，对应 `start_time`。 |
| 结束时间 | datetime | N | 风险关闭或计划结束时间，对应 `end_time`。 |
| 计划完成时间 | datetime | N | 风险处置计划完成时间，对应 `planned_complete_time`。 |
| 识别Agent | string | N | 识别或登记该风险的 Agent 名称，对应 `agent_name`（如 `manage_agent`）。 |
| 风险类型 | string | N | 更细粒度的风险类型标签，对应 `risk_type`。 |
| 关闭说明 | string | N | 风险关闭时的结论或处置说明，对应 `closed_notes`。 |
| 来源 | string | N | 风险来源（如 Agent 自动识别、责任人姓名），对应 `SOURCE`。 |
| 风险编码 | string | N | 外部风险编码，对应 `risk_code`。 |
| 源系统链接 | string | N | 源系统跳转链接，对应 `source_system_url`。 |
| 创建时间 | datetime | N | 记录创建时间，对应 `CREATED_AT`。 |
| 更新时间 | datetime | N | 记录最后更新时间，对应 `UPDATED_AT`。 |
