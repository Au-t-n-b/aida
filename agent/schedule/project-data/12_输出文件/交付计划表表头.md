# 交付计划表表头

## 一、文档作用

本文档描述 `交付计划表.xlsx` 的表头结构，用于后续模型读取最终交付计划活动任务明细，按活动、责任人、计划时间、状态、管理单元和设备列表进行检索与对账。

## 二、表头字段

| 字段     | 类型       | 必填  | 说明               |
| ------ | -------- | --- | ---------------- |
| 记录ID   | string   | Y   | 交付计划记录唯一标识。      |
| 待办ID   | string   | N   | 关联待办标识。          |
| 序号     | string   | N   | 任务或活动序号。         |
| 活动ID   | string   | Y   | 活动编号。            |
| 活动名称   | string   | Y   | 活动中文名称。          |
| 任务层级   | string   | N   | 任务层级或排序等级。       |
| 父任务ID  | string   | N   | 父级任务标识。          |
| 项目编号   | string   | Y   | 项目唯一标识。          |
| 指令     | string   | N   | 任务执行指令。          |
| 格式化指令  | string   | N   | 格式化后的任务执行指令。     |
| 源角色    | string   | N   | 任务来源角色或源 Agent。  |
| 目标角色   | string   | N   | 任务目标角色或目标 Agent。 |
| 计划开始时间 | datetime | N   | 计划开始日期。          |
| 计划结束时间 | datetime | N   | 计划结束日期。          |
| 实际开始时间 | datetime | N   | 实际开始日期。          |
| 实际结束时间 | datetime | N   | 实际结束日期。          |
| 状态     | string   | N   | 任务状态。            |
| 进度     | string   | N   | 任务执行进度。          |
| 责任人    | string   | N   | 任务责任人。           |
| 责任人公司  | string   | N   | 责任人所属公司或组织。      |
| 场景     | string   | N   | 项目或任务场景。         |
| 创建人    | string   | N   | 记录创建人。           |
| 创建时间   | datetime | N   | 记录创建时间。          |
| 最后更新人  | string   | N   | 最后更新人。           |
| 最后更新时间 | datetime | N   | 最后更新时间。          |
| 分组ID   | string   | N   | 任务分组标识。          |
| 原始设备列表 | string   | N   | JSON 或文本形式的设备列表。 |
| 任务备注   | string   | N   | 任务补充说明。          |
| 管理单元   | string   | N   | 管理单元，如机房-PoD。    |
| 所有人    | string   | N   | 任务 owner 或归属人。   |
| 人工进度   | string   | N   | 人工维护的进度字段。       |
| 实际管理单元 | string   | N   | 实际执行关联的管理单元。     |
