# 计划基线表头

## 一、文档作用

本文档描述 `计划基线0609.xlsx` 中 `集群集成 + A3液冷场景活动&依赖&工时(1014）` sheet 的表头结构，用于后续模型检索 A3 液冷场景下的一级/二级活动、依赖关系、所属阶段、标准工时、风险规则和预案责任人。

## 二、表头字段

| 字段       | 类型     | 必填  | 说明                                     |
| -------- | ------ | --- | -------------------------------------- |
| 序号       | string | Y   | 活动 WBS 编号，如 `2.3`。                     |
| 一级活动     | string | Y   | 一级活动名称。                                |
| 二级活动     | string | Y   | 二级活动名称。                                |
| SS       | string | N   | Start-to-Start 依赖，表示本活动开始与其他活动开始的关系。   |
| SF       | string | N   | Start-to-Finish 依赖，表示本活动开始与其他活动结束的关系。  |
| FS       | string | N   | Finish-to-Start 依赖，表示本活动开始依赖其他活动结束。    |
| FF       | string | N   | Finish-to-Finish 依赖，表示本活动结束与其他活动结束的关系。 |
| 所属阶段     | string | Y   | 活动所属阶段编号或阶段标识。                         |
| 备注       | string | N   | 活动备注。                                  |
| 作用域      | string | Y   | 活动作用域：机房级 / 项目级 / PoD级 / 批次级（阶段分组行为空）。该字段按固定 J 列读取，不按表头名匹配。2026-06-10 新增。 |
| 标准工时     | string | N   | 标准场景下的活动工时。                            |
| 极限工时     | string | N   | 极限压缩场景下的活动工时。                          |
| SLA形态    | string | N   | 固定 / 规模分档 / 弹性；机房准备与到货类为 `—`（工期由机房就位/到货日锚定，不读 SLA）。2026-06-10 新增。 |
| 工时备注     | string | N   | 工时口径或规模假设说明。                           |
| 分工       | string | N   | 活动分工或责任角色。                             |
| 风险判断逻辑   | string | N   | 风险触发或判断逻辑。                             |
| 风险名称     | string | N   | 风险名称。                                  |
| 风险描述     | string | N   | 风险详细描述。                                |
| 风险影响     | string | N   | 风险对排期或交付的影响。                           |
| 风险应对预案   | string | N   | 风险应对措施或预案。                             |
| 预案对应的责任人 | string | N   | 风险预案责任人。                               |
