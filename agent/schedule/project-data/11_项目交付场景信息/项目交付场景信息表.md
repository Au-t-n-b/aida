# 项目交付场景信息表头

## 一、文档作用

本文档描述 `项目交付场景信息表.xlsx` 的表头结构，用于后续模型按产品代际、制冷方式、集群形态、PoD 形态、部署阶段、算力规模、产品规模、卡数和交付模式识别项目交付场景。该表提供项目级输入参数，不能在代码中硬编码具体项目实例值。

## 二、表头字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 产品代际 | string | Y | 产品代际或产品形态，如 A3。 |
| 制冷方式 | string | Y | 制冷或散热方式，如液冷。 |
| 集群形态 | string | Y | 集群业务形态，如训推。 |
| PoD形态 | string | Y | PoD 组织形态，如多POD。 |
| 部署阶段 | string | Y | 项目部署阶段，如新建。 |
| 算力规模 | string | Y | 项目规模口径，如标准项目。 |
| 产品规模 | string | Y | 产品规模档位，如千卡。 |
| 卡数 | number | Y | 项目 GPU/加速卡数量。 |
| 算力集群交付模式 | string | Y | 算力集群交付模式，如集群集成。 |
