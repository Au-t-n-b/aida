# 设备到货表头

## 一、文档作用

本文档描述 `04 JD三期_A3液冷到货表_260309.xlsx` 的表头结构，用于后续模型按管理单元、机房、PoD、设备类型、型号和到货日期检索设备到货数据，支撑到货齐套校验和排期回灌。

## 二、表头字段

| 字段   | 类型       | 必填  | 说明                                   |
| ---- | -------- | --- | ------------------------------------ |
| ID   | number   | Y   | 行序号或到货记录唯一标识。                        |
| 管理单元 | string   | Y   | 管理单元，通常为机房-PoD 粒度，如 `B2DH401-POD01`。 |
| 设备类型 | string   | Y   | 设备或物料类型，如灵衢线缆、计算柜、总线设备柜等。            |
| 型号   | string   | Y   | 设备型号或物料型号。                           |
| 总配置  | string   | N   | 设备配置、配套关系或总配置说明。                     |
| 单位   | string   | Y   | 数量计量单位，如根、柜、台等。                      |
| 数量   | number   | Y   | 到货数量。                                |
| 到货日期 | datetime | N   | 实际或预计到货日期。                           |
| 备注   | string   | N   | 补充说明。                                |
| 机房   | string   | N   | 机房编号或机房名称。                           |
| PoD  | string   | N   | PoD 编号，如 `POD01`。                    |
