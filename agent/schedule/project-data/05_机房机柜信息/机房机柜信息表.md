# 机房机柜信息表头

## 一、文档作用

本文档描述 `机房机柜信息表.xlsx` 的表头结构，用于后续模型按 PoD、机房和各类机柜编号检索机房机柜映射关系，支撑设备定位、机柜资源查询和排期上下文补全。

## 二、表头字段

| 字段       | 类型     | 必填  | 说明                               |
| -------- | ------ | --- | -------------------------------- |
| PoD名称    | string | Y   | PoD 名称或管理单元名称，如 `B2DH401-POD01`。 |
| 机房名称     | string | Y   | 机房编号或机房名称。                       |
| 计算柜      | string | N   | 计算柜编号，可为空或包含多个机柜编号。              |
| 总线柜      | string | N   | 总线柜编号，可为空或包含多个机柜编号。              |
| 参数面Leaf柜 | string | N   | 参数面 Leaf 柜编号，可为空或包含多个机柜编号。       |
| 样本面Leaf柜 | string | N   | 样本面 Leaf 柜编号，可为空或包含多个机柜编号。       |
| 业务面Leaf柜 | string | N   | 业务面 Leaf 柜编号，可为空或包含多个机柜编号。       |
| 管理面柜     | string | N   | 管理面柜编号，可为空或包含多个机柜编号。             |
