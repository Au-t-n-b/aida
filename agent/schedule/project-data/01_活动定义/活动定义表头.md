# 活动定义表头

## 一、文档作用

本文档描述 `A3-液冷-活动定义.xlsx` 的表头结构，用于后续模型按活动 ID、活动名称和 SLA 查询活动主数据，为活动依赖、活动角色和计划基线提供统一活动字典。

## 二、表头字段

| 字段   | 类型     | 必填  | 说明                   |
| ---- | ------ | --- | -------------------- |
| 活动ID | string | Y   | 活动编号，如 `3.1`、`8.12`。 |
| 活动名称 | string | Y   | 活动中文名称。              |
| SLA  | string | N   | 活动标准周期或服务时限，如 `3天`。  |

## 三、md 表头与 Excel 变量映射

| md字段 | Excel变量 | Excel文件 | Sheet | 表头行 | 说明 |
|---|---|---|---|---|---|
| 活动ID | ACTIVITY_ID | `A3-液冷-活动定义.xlsx` | `sheet0` | 1 | 活动编号。 |
| 活动名称 | ACTIVITY_NAME | `A3-液冷-活动定义.xlsx` | `sheet0` | 1 | 活动名称。 |
| SLA | SLA | `A3-液冷-活动定义.xlsx` | `sheet0` | 1 | 活动标准周期或 SLA。 |
