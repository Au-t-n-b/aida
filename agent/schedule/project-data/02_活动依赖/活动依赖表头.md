# 活动依赖表头

## 一、文档作用

本文档描述 `A3-液冷-活动依赖.xlsx` 的表头结构，用于后续模型按项目场景、产品形态、阶段、前置活动、后继活动等字段检索活动依赖边，并与 `mermaid` 目录中的活动依赖图互相印证。

## 二、表头字段

| 字段     | 类型       | 必填  | 说明                     |
| ------ | -------- | --- | ---------------------- |
| 依赖关系ID | number   | Y   | 活动依赖关系唯一标识。            |
| 阶段编号   | number   | Y   | 当前依赖所属阶段编号。            |
| 前置活动阶段 | number   | Y   | 前置活动所属阶段。              |
| 后继活动阶段 | number   | Y   | 后继活动所属阶段。              |
| 版本号    | number   | Y   | 活动依赖版本。                |
| 项目编号   | string   | Y   | 项目唯一标识。                |
| 项目场景   | string   | Y   | 项目场景，如集群集成。            |
| 产品形态   | string   | Y   | 产品形态，如 A3。             |
| 散热方式   | string   | Y   | 散热方式，如 liquid_cooling。 |
| 阶段分类   | string   | Y   | 阶段或活动分类名称。             |
| 产品组    | string   | N   | 产品组或设备组信息。             |
| 前置活动ID | string   | Y   | 前置活动 ID。               |
| 前置活动名称 | string   | Y   | 前置活动名称。                |
| 后继活动ID | string   | Y   | 后继活动 ID。               |
| 后继活动名称 | string   | Y   | 后继活动名称。                |
| 记录状态   | string   | Y   | 记录启用、停用或流程状态。          |
| 创建时间   | datetime | Y   | 记录创建时间。                |
| 创建人    | string   | Y   | 记录创建人。                 |
| 更新时间   | datetime | Y   | 记录更新时间。                |
| 更新人    | string   | Y   | 记录更新人。                 |
| 项目规模   | string   | N   | 项目规模，如标准项目。            |
