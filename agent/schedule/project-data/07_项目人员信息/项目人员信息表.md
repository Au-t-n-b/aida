# 项目人员信息表头

## 一、文档作用

本文档描述 `03 项目人员信息表_JD_0114.xlsx` 的表头结构，用于后续模型按人员姓名、工号、项目角色等字段检索项目人员主数据，并将活动角色映射到具体责任人。

## 二、表头字段

| 字段  | 类型     | 必填  | 说明                              |
| --- | ------ | --- | ------------------------------- |
| 姓名  | string | Y   | 项目人员姓名。                         |
| 工号  | string | Y   | 人员工号，作为人员唯一标识使用。                |
| 角色  | string | Y   | 项目角色，如 PD、DPD、PCM、TD、作业管理 TL 等。 |
| 备注  | string | N   | 组织归属、补充说明或其他备注信息。               |

## 三、md 表头与 Excel 变量映射

| md字段 | Excel变量 | Excel文件 | Sheet | 表头行 | 说明 |
|---|---|---|---|---|---|
| 姓名 | 姓名 | `03 项目人员信息表_JD_0114.xlsx` | `Sheet1` | 1 | 直接对应。 |
| 工号 | 工号 | `03 项目人员信息表_JD_0114.xlsx` | `Sheet1` | 1 | 直接对应。 |
| 角色 | 角色 | `03 项目人员信息表_JD_0114.xlsx` | `Sheet1` | 1 | 直接对应。 |
| 备注 | 备注 | `03 项目人员信息表_JD_0114.xlsx` | `Sheet1` | 1 | 直接对应。 |
