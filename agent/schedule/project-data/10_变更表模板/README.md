# 变更表模板

这是 T-013 新增的系统生成资产目录，区别于 `02_项目数据/01~10` 的业务源表。

- `调整表模板.xlsx`：固定三 sheet 模板，无嵌入图片；[到货] sheet 只保留跨项目一致的设备级表头，下载接口会按当前项目 `06_到货表` 预填设备清单。
- `stage-2-调整表-样例.xlsx`：两阶段故事线样例；[到货] sheet 为设备级，一行一设备，解析时按「管理单元」取最大到货日期。
- `表头.md`：模板表头与字段含义说明。

重生成方式：在仓根创建三张 sheet，表头保持与 `表头.md` 完全一致。该模板只承载上传入口的确定性变更解析，不作为业务源表维护。
