# 变更表固定模板表头

> T-013 系统生成资产，T-050 起 [到货] sheet 升为设备级，用于“上传变更表”确定性解析为 `ChangeSet`。机房 ready / 批次目标空单元格表示该字段不变；[到货] sheet 的设备行来自当前项目预填，`到货日期` 需逐行填写，空日期会告警且不参与聚合。

## 机房ready

| 列名 | 含义 |
| --- | --- |
| 机房id | 当前盘子里的机房 id |
| 可布线 | 可布线日期，格式 `YYYY-MM-DD` |
| 可装设备 | 可装设备日期，格式 `YYYY-MM-DD` |
| 可通液 | 可通液日期，格式 `YYYY-MM-DD` |

## 到货

| 列名 | 含义 |
| --- | --- |
| 管理单元 | 当前盘子里的 PoD / 管理单元 id，对应 `06_到货表` 的「管理单元」列 |
| 设备类型 | 设备类型，下载模板时从当前项目 `06_到货表` 预填 |
| 型号 | 设备型号，下载模板时从当前项目 `06_到货表` 预填 |
| 数量 | 设备数量，下载模板时从当前项目 `06_到货表` 预填 |
| 单位 | 数量单位，下载模板时从当前项目 `06_到货表` 预填 |
| 到货日期 | 该设备实际或预计到货日期，格式 `YYYY-MM-DD`；上传解析按同一「管理单元」取最大日期作为该 PoD 到货日 |

## 批次目标

| 列名 | 含义 |
| --- | --- |
| batch_id | 当前盘子里的批次 id |
| 上电目标 | 批次上电目标日期，格式 `YYYY-MM-DD` |
| 上线目标 | 批次上线目标日期，格式 `YYYY-MM-DD` |
