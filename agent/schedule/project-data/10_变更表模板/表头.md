# 变更表固定模板表头

> T-013 系统生成资产，用于“上传变更表”确定性解析为 `ChangeSet`。空单元格表示该字段不变。

## 机房ready

| 列名 | 含义 |
| --- | --- |
| 机房id | 当前盘子里的机房 id |
| 可布线 | 可布线日期，格式 `YYYY-MM-DD` |
| 可装设备 | 可装设备日期，格式 `YYYY-MM-DD` |
| 可通液 | 可通液日期，格式 `YYYY-MM-DD` |

## 到货

| 列名 | 含义 |
| --- | --- |
| pod_id | 当前盘子里的 PoD id |
| 到货日期 | 实际或预计到货日期，格式 `YYYY-MM-DD` |

## 批次目标

| 列名 | 含义 |
| --- | --- |
| batch_id | 当前盘子里的批次 id |
| 上电目标 | 批次上电目标日期，格式 `YYYY-MM-DD` |
| 上线目标 | 批次上线目标日期，格式 `YYYY-MM-DD` |
