# stage-2 变更单样例（测试用）

文件：`stage-2-变更单-样例.xlsx`（与本说明同目录；测试启动见仓根 `测试启动指南.md`）

用途：供手动串联“两阶段故事线”时上传解析（原 T-037 fixture，2026-06-14 移到此处便于测试取用）。stage-1 源表状态为 06 到货日期全空、机房 ready 全空；stage-2 通过这张变更单补入业务确认后的机房 ready、PoD 到货齐套日和批次上电/上线目标，再触发 `/adjust` 重算。

## 数据口径

- `机房ready`：一行一机房，三段 ready 日期均给定；列名与 `02_项目数据/10_变更表模板/表头.md` 完全一致。
- `到货`：一行一 PoD，`到货日期` 为该 PoD 设备齐套日期；批次 1 使用 2026-01-10，批次 2 使用 2026-01-19，批次 3 使用 2026-03-05。
- `批次目标`：沿当前 `09_批次信息` 的三批目标口径：批次1 2026-01-21/2026-02-04，批次2 2026-01-25/2026-02-04，批次3 2026-03-17/2026-04-04。
