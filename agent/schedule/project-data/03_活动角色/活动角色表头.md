# 活动角色表头

## 一、文档作用

本文档描述 `活动角色表.xlsx` 的表头结构，用于后续模型按项目场景、产品形态、散热方式、活动层级、SLA、远程/现场参与标记和责任角色检索活动角色配置数据。该表是活动字典与项目交付角色/工期口径之间的映射，不是项目实例任务清单。

## 二、表头字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 关系ID | number | Y | 活动角色配置记录唯一标识。 |
| 项目编号 | string | Y | 项目或场景编号。 |
| 项目场景 | string | Y | 项目交付场景，如集群集成。 |
| 产品形态 | string | Y | 产品代际或产品形态，如 A3。 |
| 散热方式 | string | Y | 散热方式，如 `liquid_cooling`。 |
| 活动ID | string | Y | 活动编号，如 `3.1`、`8.12`。 |
| 活动名称 | string | Y | 活动中文名称。 |
| 父活动ID | string | N | 父级活动编号；一级活动为空。 |
| 父活动名称 | string | N | 父级活动名称；一级活动为空。 |
| 活动层级 | number | Y | 活动层级，当前源表使用 `1`、`2`。 |
| 标准SLA | string | N | 标准场景下的活动周期或服务时限。 |
| 极限SLA | string | N | 极限压缩场景下的活动周期或服务时限。 |
| 远程标记 | string | N | 远程侧参与/责任标记，源表使用 `R`、`S` 等值；具体口径以业务解释为准。 |
| 现场标记 | string | N | 现场侧参与/责任标记，源表使用 `R`、`S` 等值；具体口径以业务解释为准。 |
| 责任角色 | string | N | 活动主要责任角色，如 PD、TD、规划设计 TL、DC L1 工勘专家。 |
| 所属阶段 | number | Y | 活动所属排期阶段编号。 |
| 项目规模 | string | N | 项目规模口径，如标准项目。 |
