# 项目数据索引

> 生成日期：2026-06-11（2026-06-12 随目录重排更新；2026-06-12 增补项目交付场景与计划基线 sheet 索引；2026-06-13 11 表接管项目名称与卡数；2026-06-13 增补机房 ready 源表与 stage-1 到货空值口径）
> 根目录：`02_项目数据`
> 用途：为后续系统提供渐进式加载入口。系统应先读取本索引，再按任务需要加载对应文件夹内的表头 md、Excel 数据或 Mermaid 依赖图。

## 读取建议

1. 优先读取本索引，判断需要进入哪个业务文件夹。
2. 需要理解字段含义时，优先读取对应表头 md。
3. 需要读取实际数据时，再按索引中的 Excel 文件路径加载工作簿。
4. 需要读取活动依赖 Mermaid 图时，先读 `02_活动依赖\mermaid\活动依赖Agent查询操作文档.md`，再按文档步骤读取对应 `.mmd` 文件。
5. `04_计划基线\计划基线0609.xlsx` 文件较大，A3 液冷场景只定向加载 `集群集成 + A3液冷场景活动&依赖&工时(1014）` sheet。

## 文件夹加载顺序建议

1. 活动查询：先读 `01_活动定义`，再读 `02_活动依赖` 或 `03_活动角色`。
2. 排期生成：先读 `11_项目交付场景信息` 判断项目级场景参数，再读 `04_计划基线`（只取 A3 液冷目标 sheet）、`01_活动定义`、`02_活动依赖`，再读 `09_批次信息`（批次锚点/目标日期）、`06_到货表`、`05_机房机柜信息`（含机房 ready 源表）、`07_项目人员信息`、`08_施工队伍信息`（人力/产能）。
3. 结果对账：先读 `12_输出文件`，再按字段回溯 `03_活动角色`、`06_到货表`、`04_计划基线`。
4. 依赖图展示：先读 `02_活动依赖\mermaid\活动依赖Agent查询操作文档.md`，再读 `02_活动依赖\活动依赖表头.md`、`02_活动依赖\mermaid\活动依赖映射0609.md` 和对应 `.mmd`。
5. 风险解释：先读 `04_计划基线`（活动风险五列规则），再读 `12_输出文件\风险信息\风险信息表.md` 与 `风险应对措施表.md`，按 `问题ID` 串联措施（注意：该目录为输出侧落表形态，引擎/导入器暂不读取）。
