## 三、决策点信息

### 3.1 核心决策点

| 项 | 内容 |
| --- | --- |
| 决策点名称 | 方案可交付性 |
| 决策问题 | 决策方案是否可交付 |
| 判定依据 | 当前预案/方案快照（As-Is）与目标要求（Should-Be）的匹配度 |
| 输出 | 可交付结论、四域可交付指数、Gap、任务与风险 |

### 3.2 子决策点

| 子决策点编号 | 子决策点名称 | 决策问题 |
| --- | --- | --- |
| 子决策点-1 | 组网配置的可交付性 | 组网（含网络平面、服务器网络、软件版本配套、预集成验证）能否满足连通性、带宽、平面隔离及器件可交付 |
| 子决策点-2 | 设备配置的可交付性 | 设备与部件清单、版本、生命周期、空间与功耗能否在目标机房落地 |
| 子决策点-3 | 服务配置的可交付性 | 服务交付界面、服务内容、维保策略、SLA、责任矩阵能否覆盖合同并按期交付 |
| 子决策点-4 | 验收的可交付性 | 验收策略能否和客户需求匹配并形成可签收闭环 |

### 3.3 全局输入说明

以下章节不单独对应某一个子决策点，作为**四个子决策点的共同输入**参与核心决策：

- 元数据信息
- 1. 客户需求信息 / 1.1 项目信息 / 1.2 合同信息（含交付场景与范围）
- 9. 风险&假设信息 / 9.1 风险列表 / 9.2 假设
